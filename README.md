# 🔐 Cybersecurity Log Analyzer

A Python-based cybersecurity project that analyzes system log files and helps identify suspicious activities such as failed login attempts, repeated access attempts, and unusual IP activity.

## 📌 Project Overview

The Cybersecurity Log Analyzer is designed to analyze log data and extract useful security information.

It processes log entries, identifies important security events, and generates a simple analysis that can help in detecting potentially suspicious activities.

This project is developed as a learning project for understanding cybersecurity, Python programming, and basic security log analysis.

## 🎯 Objectives

- Analyze system log files using Python
- Detect failed login attempts
- Identify suspicious IP addresses
- Count security-related events
- Extract useful information from log data
- Understand the basic process of security monitoring

## 🚀 Features

- 📄 Log file analysis
- 🔍 Failed login detection
- 🌐 IP address analysis
- ⚠️ Suspicious activity identification
- 📊 Basic log statistics
- 🐍 Python-based implementation
- ☁️ Google Colab compatible

## 🛠️ Technologies Used

- Python
- Google Colab
- Jupyter Notebook
- Regular Expressions (Regex)
- Pandas
